# 完整版本验收

日期：2026-10-29。范围：个人作品展示版本，业务源码独立实现。该文件记录实际验证及仍需验证的环境，不将配置存在视为测试通过。

## 已实现的完整流程

学生注册、登录、查看公开活动、报名、查看本人记录、取消、重新报名；组织者创建与编辑草稿、发布、查看名单、在活动时间内核验签到；退出撤销当前会话。

实现了可选 Redis 静态元信息缓存、浏览器页面、Windows 独立数据库启动脚本、健康检查、就绪检查、请求日志、SQL 初始化、Docker Compose 和 CI 配置。

## 本地验证环境

- Windows，Go 1.27.2，CGO_ENABLED=0。
- 真实 MySQL 5.7.44：仅复用已安装的可执行文件，不启动系统服务；专用临时数据目录与测试库。
- 独立测试库 campus_events_full_test；本地演示脚本另使用 campus_events_local 和独立端口 33088。
- Redis 测试使用 miniredis 协议兼容实例及真实 go-redis 客户端；没有实跑本机 Redis 服务。

## 自动化验证

| 场景 | 实测结果 |
| --- | --- |
| 20 个不同学生并发争抢 5 个名额 | 恰好 5 次成功，其他返回 EVENT_FULL；有效报名数与计数均为 5 |
| 同一学生 20 次并发重复报名 | 只有一个有效报名、只占一个名额 |
| 同一学生 20 次并发重复取消 | 只释放一个名额，没有出现负数 |
| 取消后重新报名 | 复用原报名 ID，名额恢复正确 |
| 插入报名后注入计数更新失败 | 真实 SQL 事务回滚，报名记录不残留 |
| 草稿公开查询 | 404 |
| 学生尝试创建活动或组织者尝试学生报名 | 403 |
| 注册请求携带 role=organizer | 400，未知字段被拒绝 |
| 跨组织者编辑、查看名单和签到 | 403 |
| 发布后编辑活动 | 409 |
| 提前签到、有效签到与重复签到 | 提前返回 409；有效签到成功，重复保持同一毫秒时间戳 |
| 报名截止后取消 | 409，人数不变 |
| 错误密码、伪造令牌、过期令牌 | 401 |
| 退出后重新使用旧令牌 | 401 |
| Redis 命中后发生取消 | 详情仍返回 MySQL 的最新人数 |
| Redis 不可用 | 回源 MySQL，详情仍正确 |
| 认证基础限流 | 同 IP 第 31 次触发 429，不误限另一个 IP |
| 空列表、分页边界、非法 ID 与内部错误隐藏 | 通过 |

这些是正确性验证，不是高吞吐压测；不能据此宣称支持某个 QPS 或用户规模。测试中失败注入只在测试 GORM 实例上注册回调，移除后恢复正常，不作为生产行为。

## 浏览器操作验证

已用应用内浏览器实际操作并观察结果：学生登录、报名、我的报名、取消、退出；组织者登录、查看活动、编辑草稿、发布、查看名单、核验签到。保存了首页、管理页和签到结果截图。

浏览器验收中发现并修复：退出引起重复渲染、活动列表重复追加；异步按钮事件对象失效；未报名时详情错误显示取消按钮。查询接口补充了本人报名状态，页面只在存在有效报名时显示取消入口。

## 范围与局限

单个活动行锁串行处理名额更新，热点活动可能受锁竞争限制；限流为进程内基础方案；Redis 命中仍有一次轻量数据库名额查询，当前没有缓存性能提升结论。

演示账号和本地配置用于学习与展示，首次对外部署应自行配置 HTTPS、独立账号和密钥。没有真实校园用户、运营数据或生产可用性承诺。源码已上传 https://github.com/Blessing-BOS/campus-events ，本地运行数据及真实配置未提交。
