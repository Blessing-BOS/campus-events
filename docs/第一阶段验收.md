## 环境

- Windows，Go 1.27.2 windows/amd64。
- Go 模块要求 Go 1.24.0；更低版本未测试。
- Gin 1.11.0、GORM 1.31.1、GORM MySQL driver 1.6.0、go-sql-driver/mysql 1.8.1；传递依赖见 go.mod 和 go.sum。
- 真实数据库联调：本机已有 MySQL 5.7.44 可执行文件，独立数据目录 `.run/mysql-stage1-data`，仅监听 127.0.0.1:33087。
- 数据库使用专用 `campus_events_stage1_verified_test`，未使用系统 MySQL 服务的数据目录。MySQL 8.4 尚未实际验证。

HTTP 测试另覆盖：草稿详情返回 404、空列表返回 []、重复与越界分页参数返回 400、内部数据库错误不出现在响应中。业务单元测试覆盖活动状态的时间边界和请求取消。

真实数据库测试覆盖：重复执行建表、已发布过滤、ID 排序与排他游标、详情时间的 UTC 往返、请求取消，以及 seed 重复运行不重复创建活动。

联调中发现并修复了 seed 用户名缺失的问题：GORM 的字符串 WHERE 条件不会自动填入新建记录，因此改为显式设置 Username，并在真实数据库测试中验证创建结果。
